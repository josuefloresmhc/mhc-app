# Client Avatar & Hook Bank Generator

A single-page web app for social media agency owners. Fill in a client
onboarding form, hit **Generate**, and get a client avatar plus a bank of 10
hooks — generated by the Anthropic Claude API (`claude-sonnet-4-6`).

Nothing is stored. Everything resets when you reload the page. No database, no
accounts, no logins.

## Run it locally

1. Clone the repo:

   ```bash
   git clone https://github.com/josuefloresmhc/mhc-app.git
   cd mhc-app
   ```

2. Add your API key. Copy the example env file and paste your key into it:

   ```bash
   cp .env.local.example .env.local
   ```

   Then open `.env.local` and replace `your-key-here` with a real key from
   https://console.anthropic.com/settings/keys

3. Install and start:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000

## Deploy to Vercel (from GitHub)

1. Go to https://vercel.com, click **Add New → Project**, and import the
   [mhc-app](https://github.com/josuefloresmhc/mhc-app) repo.
2. In the project's **Settings → Environment Variables**, add:
   - Name: `ANTHROPIC_API_KEY`
   - Value: your Anthropic API key
3. Click **Deploy**.

Vercel auto-detects Next.js — no extra configuration needed.

## Project structure

- `app/page.tsx` — the form and the results (avatar + hook bank).
- `app/api/generate/route.ts` — server route that calls the Claude API.
- `app/globals.css` — styling.

> ⚠️ Never commit your API key. `.env.local` is already in `.gitignore`.
